# Lit Review Studio

A dyslexia-friendly workspace for a literature review on how leadership and management is understood and enacted for a neurodiverse school workforce in state-funded schools in England.

`index.html` is a single page published as a claude.ai Artifact. It has three rooms:

1. **Sources**: an evidence table with guided short-answer prompts (aim, method, sample, findings, weak spots, relevance), theme tags, saved quotes and Harvard references.
2. **Read**: paste text or open a PDF; read aloud with word highlighting, focus mode, a reading ruler, adjustable font, spacing and page tint, plus plain-English summaries and draft table notes from Claude.
3. **Map**: drag sources and themes on a board and draw links (supports, contradicts, builds on, shows a gap). Tapping a theme lists its sources and gives sentence starters.

Data is saved privately per person through the Artifact `db` capability, or in browser storage when opened as a plain file.
